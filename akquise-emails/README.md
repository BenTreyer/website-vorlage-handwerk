# Akquise-E-Mails

Eine E-Mail pro Firma, passend zum jeweiligen Website-Ordner im selben Repo.
Ordner `akquise-emails/<slug>/email.md` gehört zu `website-<slug>/`.

Basis-Vorlage (Stilregeln, Herleitung): Obsidian `02 Projekte/Akquise E-Mail Vorlage.md`.

Enthält nur die 27 Firmen mit sauberem, committetem Website-Stand (keine sichtbaren
TODO-Platzhalter). Folgende 6 Firmen fehlen bewusst, da ihre committete Version noch
TODO-Lücken hat (siehe `git show HEAD:<ordner>/index.html`):

- website-bene-environmental
- website-blumen-dinger
- website-elektro-wiegele
- website-klumpp-montage-service
- website-mulag
- website-panter-holzbau

Sobald diese überarbeitet und committet sind, können ihre E-Mails ergänzt werden.
